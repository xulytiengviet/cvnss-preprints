# Template bài mới

Copy toàn bộ thư mục này thành:

```text
papers/cvnss-YYYY-NNNN/
```

Sau đó thay:

```text
paper.pdf
source.docx hoặc source.tex
abstract.md
metadata.yml
citation.bib
```

Không đưa phép chuẩn, rule table private, converter PRO hoặc dữ liệu nhạy cảm vào thư mục bài nếu chưa được phép công bố.
